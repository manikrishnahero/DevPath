# DevPath

DevPath is a Learning Management System (LMS) built for students who want to learn coding and programming languages. It gives learners one simple place to create an account, sign in securely, and study through organized courses and video lessons at their own pace.

**Live demo:** https://dev-path-seven-zeta.vercel.app

## About the Project

Many beginners struggle to find structured learning material for programming. DevPath solves this by grouping content into clear categories and programming languages, so students always know what to learn next. Administrators can upload and manage learning videos, which keeps the platform fresh and useful.

## Key Features

- Student registration with strong password rules for better account security
- Secure login using token-based authentication
- Personal dashboard to access learning content
- Courses organized by categories and programming languages
- Learning videos for practical, easy-to-follow lessons
- Admin tools to upload videos and manage courses
- Responsive design that works on desktop and mobile

## Technology

DevPath is a full-stack web application. The frontend is built with React and Vite, and the backend uses Django with Django REST Framework. Data is stored in a PostgreSQL database. The frontend is hosted on Vercel and the backend on Render.

## Who Is It For?

- Students starting their programming journey
- Self-learners exploring new programming languages
- Teachers and mentors who want to share video lessons with learners

## Future Improvements
